# 🎯 Context-Genie Frontend

🔵 A modern React-based interface that lets users interact with Context-Genie, enabling AI-powered question answering from PDF documents with page citations.

---

## ✨ Features

- 🧠 Ask natural language questions about PDF content  
- 📄 Get accurate answers with referenced page numbers  
- ⚡ Communicates seamlessly with Context-Genie backend (FastAPI)  
- 💻 Built with React and Axios  
- 🎨 Clean and responsive user interface  

---

## 🛠️ Tech Stack

| Technology       | Role                         |
|------------------|------------------------------|
| React            | UI Framework                 |
| Axios            | API Requests                 |
| JavaScript       | Programming Language         |
| CSS              | Styling                      |
| FastAPI (Backend)| Powered Context-Genie API    |
